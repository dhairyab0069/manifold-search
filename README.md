# Manifold search

Shortest paths over curved surfaces, and a coarse-to-fine search that answers them faster.

| | |
|---|---|

| [**Part 2: Independent research**](part2-research/) | My own continuation, as computational geometry: irregular and real meshes, scaling to millions of vertices with GPU-computed ground truth, what controls the error, comparison with established geodesic methods.
